### Quelques projets

- **[dna-interactive](https://github.com/pedrokarim/dna-interactive)** · TypeScript : carte interactive et ressources communautaires pour le jeu Duet Night Abyss. Six régions cartographiées, en Next.js et Bun. [En ligne](https://dna.ascencia.re/).
- **[sharex-manager](https://github.com/pedrokarim/sharex-manager)** · TypeScript : application web pour gérer ses uploads ShareX. Galerie, statistiques, clés API à permissions, miniatures automatiques, thème clair/sombre. [Démo](https://sxm.ascencia.re) et [documentation](https://pedrokarim.github.io/sharex-manager/).
- **[mc-rs](https://github.com/pedrokarim/mc-rs)** · Rust : serveur Minecraft Bedrock écrit intégralement en Rust, modulaire et extensible, avec un vrai système de plugins.
- **[info-mc-rs](https://github.com/pedrokarim/info-mc-rs)** · Rust et Svelte : plateforme d'inspection Minecraft. Ping de serveurs Java et Bedrock en direct (SLP, Query, Raknet), recherche de joueurs via l'API Mojang, rendu des skins en 2D et 3D. [En ligne](https://mcinfo.ascencia.re/).
- **[material-you-gnome](https://github.com/pedrokarim/material-you-gnome)** · JavaScript : thématisation Material You dynamique pour GNOME, la palette suit le fond d'écran.
- **[CardMyAnime](https://github.com/pedrokarim/CardMyAnime)** · TypeScript : cartes de profil générées à partir de vos données sur les différentes plateformes d'anime.

Et une soixantaine d'autres dépôts, du sérieux au parfaitement inutile.
